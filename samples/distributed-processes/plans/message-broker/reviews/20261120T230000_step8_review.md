Quote: `profiles: [ kafka, kafka-all, all, all-no-ui, ci, sample ]`. Step: "gets Kafka ... in the `sample` and `all` profiles". The earlier Step-8 finding named these profiles; its Resolution lists what was removed but not the profiles.

### Step-2. The routing consumer's error log is not asserted

Quote: `logger.error("Routing a message with key '{}' from channel '{}' to queue '{}' failed; it will be retried", ...)`. Q30 decision: "log each failed send". Belongs to: implementation
