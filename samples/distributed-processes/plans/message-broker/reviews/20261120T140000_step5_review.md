### Step-3. Default branches and casts in handlers are not run by a test

Quote: `default -> throw new IllegalArgumentException("Unexpected event ...")` in three forwarders, saga switch, authorization client switch.

Belongs to: implementation
Resolution: accepted by the coordinator under Q30: the type filter makes the branches unreachable, same style as `Projection.getDocumentId`.

### Step-4. Duplicate subscription names and empty type lists are undecided

Quote: `subscribe` accepts any name and an empty `types` list (in-memory: matches nothing; KurrentDB regex `^()$`).
Consequence: step 6 keys checkpoints by name; a repeated name would share a checkpoint.
Belongs to: spec
Resolution: decided by the coordinator under Q30, from the spec's one-name-per-subscriber rule (spec review Quality-10: a shared name loses events): `subscribe` rejects a name already in use and an empty type list, with an error naming the problem. Sent to the implementer with tests.
